## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Steam Workshop** | Automatically downloads and manages Steam Workshop mod subscriptions |
| **Load Order** | Drag-and-drop load order management with conflict highlighting |
| **Server Sync** | Export and import mod lists for seamless multiplayer server setup |
| **Version Tracking** | Track which mod versions are installed and check for available updates |
